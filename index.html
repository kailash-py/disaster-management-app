🏢 3. Operational Carrying Capacity Formula

Carrying capacity is NOT defined as mere plinth area. It is calculated deterministically:

Operational Capacity = minimum(
  Usable Shelter Plinth,
  Water Supply (person-days),
  Sanitation Fixtures,
  Healthcare Buffer,
  Food Rations,
  Road Access Capacity
)

The system explicitly displays which critical resource is constraining capacity (e.g. Water at Site B).

Explainable Algorithmic Model

⏱️ 4. Effective Relocation Window & Time-Feasibility

The core USP calculates the Last Safe Relocation Window:

Effective Window = minimum(
  Hazard Inundation Window,
  Road Passability Closure Window,
  Safe Site Readiness Window
)
Status = (Effective Window >= Required Transit Time) 
         ? "SAFE IN TIME" : "INSUFFICIENT WINDOW"

Route R2 is chosen over shorter R1 because R1 closes at 10h before 11h relocation completes.

Core Novel Algorithm
